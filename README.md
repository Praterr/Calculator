# Git Calculator

A simple command-line calculator written in Python, built to practise Git
branching, merging and conflict resolution (UCS745 Cloud and DevOps, Lab Q1).

Version: 1.2 - added power (^), modulus (%) and divide-by-zero error handling

## Run

    python calculator.py

Author: Prateek Singh (102316030, 4Q17)

## Example

    Enter first number: 2
    Enter operation ['+', '-', '*', '/', '^', '%']: ^
    Enter second number: 10
    Result: 1024.0

Dividing by zero prints `Error: Division by zero is not allowed`.
